# 第一阶段：多存储节点扩展与控制面解耦开发计划

## 一、 阶段目标与背景

由于主站服务器磁盘空间受限，且后续业务将以自建/自育视频资源为主，现计划对视频存储架构进行解耦改造：
- **目标**：实现主站（控制面/API/数据库）与首个独立存储节点（Storage Node 01 数据面）的彻底解耦。
- **效果**：主站不再承载大文件视频存储，避免主站磁盘爆满；所有新增上传视频文件均直接或代理存入独立存储节点，并保持现有播放器自适应与第 50 帧封面自动提取功能。

---

## 二、 整体架构设计（第一阶段）

```
┌──────────────────────────────────────┐
│           主站控制节点 API            │
│  (端口 3000 / 存储数据库 & VIP 逻辑)   │
└──────────────────┬───────────────────┘
                   │
                   ▼ (HTTP/HTTPS 代理与鉴权)
┌──────────────────────────────────────┐
│       独立存储节点 (Storage-Node-01)   │
│ (端口 3001 或 Nginx / 存放视频及封面)   │
└──────────────────────────────────────┘
```

1. **主站控制节点**：
   - 维持现有的 Express/Node.js API 服务。
   - 记录视频元数据信息、VIP 权限校验、订单与用户数据。
   - 增加独立存储节点配置项 `STORAGE_NODE_BASE_URL`。

2. **独立存储节点 (Storage-Node-01)**：
   - 独立运行的存储服务（可为独立的 VPS / 独立子域名节点）。
   - 负责文件接收、物理存储 (`/uploads/videos/` 与 `/uploads/posters/`)、静态文件直推。
   - 运行 FFmpeg 生成第 50 帧封面及 HLS 视频切片。

---

## 三、 数据模型与接口设计

### 1. 主站配置增加存储节点信息
在环境配置或 `settings` 表中增加：
- `storage_node_active_url`: 默认上传存储节点地址（如 `http://storage1.yourdomain.com:3001`）
- `storage_node_secret`: 主站与存储节点间通信密钥（用于上传与操作鉴权）

### 2. 核心 API 规范

| 接口类型 | 路径 | 作用说明 |
| :--- | :--- | :--- |
| **存储节点上传** | `POST /api/v1/storage/upload` | 接收视频上传，存入存储节点磁盘，自动调用 50 帧封面生成 |
| **主站中转/直传代理** | `POST /api/v1/admin/videos/upload` | 后台发起上传，主站自动路由/代理至目标存储节点 |
| **媒体流播放** | `GET /api/v1/proxy/video?id=...` | 主站根据视频存储节点 URL 进行代理推流与 VIP 鉴权 |
| **动态封面响应** | `GET /api/v1/proxy/poster?id=...` | 自动抓取存储节点上的第 50 帧封面并缓存响应 |

## 四、 开发任务分解 (Work Breakdown Structure)

### 任务 1：独立存储节点子服务开发 (`packages/storage-node` 或轻量模块)
- [ ] 创建存储节点服务代码（支持静态推流、Range 断点续传）。
- [ ] 实现视频上传接收接口（含 MD5 去重校验与文件命名规范）。
- [ ] 集成现有的 `FFmpeg` 第 50 帧封面自动提取逻辑 (`select=eq(n\,49)`).

### 任务 2：主站控制面与代理推流对接 (`packages/server`)
- [ ] 重构 index.js 中的 `/api/v1/proxy/video`，支持跨存储节点视频拉取与响应。
- [ ] 重构 db.js，视频数据模型兼容远程存储节点绝对/相对 URL。
- [ ] 实现主站上传路由分发逻辑（当上传文件时自动转发至 `STORAGE_NODE_BASE_URL`）。

### 任务 3：管理后台 (`packages/admin`) 升级
- [ ] 重构 App.vue 中的视频上传组件，显示上传进度条与存储节点状态。
- [ ] 支持输入远程存储节点 URL 或直接拖拽大文件上传。

### 任务 4：前端播放与端到端测试 (`packages/client`)
- [ ] 测试 MemoryVideoPlayer.vue 播放存储节点视频流。
- [ ] 验证横竖屏自适应与第 50 帧封面在存储节点架构下的正常呈现。

## 五、 部署与迁移步骤

1. **准备存储节点**：在目标存储服务器上配置 Node.js 环境与 FFmpeg 依赖。
2. **环境变量配置**：
   ```env
   # 主站 .env 配置
   STORAGE_NODE_01_URL=http://storage-node-01.yourdomain.com
   STORAGE_NODE_SECRET=your_secure_shared_token_here
   ```
3. **老数据无缝兼容**：保留主站既有视频路径解析，新增视频统一写入 `STORAGE_NODE_01`。
